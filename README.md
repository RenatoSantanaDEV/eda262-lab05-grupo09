# Engenharia de Dados 2026.2 - Laboratório 05

## O pipeline que pode rodar de novo

Entrega do grupo 09 da CESAR School: Renato Santana (representante),
João Augusto Pimentel, Raphael Barros e Lara Pessoa.

O laboratório implementa um pipeline de corridas em Terraform, AWS Glue,
Amazon S3 e Athena, com deduplicação, tratamento de atraso e reexecução idempotente.

A solução, as quatro decisões e as evidências de execução são apresentadas
no pull request desta atividade. A implementação parte do projeto-base
fornecido pelo professor Carlos Diego Cavalcanti Pereira.

Credenciais, estado Terraform, configuração privada do backend e cache de
provedores não devem ser versionados.
